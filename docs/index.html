Component Library

Custom HTML components built with Lit, served via CDN.

Usage

Import any component directly in your HTML or JS — no npm install required:

<!-- HTML -->
<script type="module">
  import 'https://cdn.jsdelivr.net/gh/Seth-Harlaar/sp-components@latest/components/component-name.js'
</script>
// JS / ES module
import 'https://cdn.jsdelivr.net/gh/Seth-Harlaar/sp-components@latest/components/component-name.js'

Available Components

  • sp-button — Button with variants and sizes
  • sp-card — Content card with optional hover lift and accent bar
  • sp-nav — Header nav bar with brand, links, and actions slots
  • sp-tag — Pill-shaped label with semantic color variants
  • sp-theme — Theme loader and CSS custom property scope
