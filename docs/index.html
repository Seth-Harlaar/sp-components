Component Library

Custom HTML components built with Lit, served via CDN.

Usage

Import any component directly in your HTML or JS — no npm install required:

<!-- HTML -->
<script type="module">
  import 'https://cdn.jsdelivr.net/gh/{username}/{repo}@latest/components/component-name.js'
</script>
// JS / ES module
import 'https://cdn.jsdelivr.net/gh/{username}/{repo}@latest/components/component-name.js'

Replace {username}, {repo}, and component-name with your GitHub username, repo name, and the component filename.

Adding a Component

  1. Create a .js file in components/
  2. Import Lit at the top: import { LitElement, html, css } from 'https://esm.sh/lit@3'
  3. Define and register your element
  4. Commit and push — it's immediately available on the CDN
  5. Add it to the list above
