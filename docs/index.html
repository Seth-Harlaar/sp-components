Component Library

Custom HTML components built with Lit, served via CDN.

Usage

Import any component directly in your HTML or JS — no npm install required:

<!-- HTML -->
<script type="module">
  import 'https://cdn.jsdelivr.net/gh/Seth-Harlaar/sp-components@latest/components/component-name.js'
</script>
// JS / ES module
import 'https://cdn.jsdelivr.net/gh/Seth-Harlaar/sp-components@latest/components/component-name.js'

Available Components

  • sp-theme — Loads theme CSS and sets data-theme. Attr: name (default, dark, …)
  • sp-card — Content card with optional hover lift and accent bar. Attrs: interactive, accent
  • sp-button — Button with variants and sizes. Attrs: variant (default/primary/outline/ghost), size (sm/md/lg), full, disabled
  • sp-tag — Pill-shaped label. Attr: color (primary/success/warning/error/info)
  • sp-nav — Header nav bar with brand/links/actions slots. Attr: sticky
